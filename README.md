# ブロック崩し

ブラウザで遊べるシンプルなブロック崩しゲームです。インストール不要で、PC でもスマホでも遊べます。

## ▶ プレイ

**https://ogitet.github.io/breakout/**

## 遊び方

パドルでボールを打ち返して、すべてのブロックを壊せばクリアです。

### 操作

| 操作 | PC | スマホ |
|---|---|---|
| パドルを動かす | ← → キー / マウス | 画面をスライド |
| ボールを発射 | スペース / クリック | タップ |
| 一時停止・再開 | P | — |
| リトライ | スペース / クリック | タップ |

### ルール

- 残機は 3 つ。ボールを下に落とすと 1 つ減り、0 になるとゲームオーバーです。
- ブロックは上の段ほど高得点です（下から 10・20・30・40・50 点）。
- パドルの端で打ち返すほど、ボールが斜めに飛びます。
- ブロックを壊すたびに、ボールが少しずつ速くなります。

## ローカルで遊ぶ

`index.html` をブラウザで開くだけで動きます。ビルドも依存パッケージも要りません。

ボールの速さやパドルの幅は、`index.html` 内の「設定」の数値を変えると調整できます。
